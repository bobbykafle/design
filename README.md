# Authentication UI — Flutter

A clean and customizable Flutter authentication UI built for **learning and practice purposes**.

The project focuses on creating reusable authentication screens, custom form fields, validation, and a simple UI structure without unnecessary complexity.

## ✨ Features

- Custom Sign In screen
- Custom Sign Up screen
- Forgot Password
- OTP Verification
- Change Password
- Form validation
- Reusable text fields
- Reusable buttons
- Custom colors, fonts, and styling
- Clean and consistent UI
- Responsive layout

## 🔐 Authentication Flow

```text
Sign In
   ↓
Forgot Password
   ↓
OTP Verification
   ↓
Change Password
   ↓
Password Updated
```

New users can follow:

```text
Sign Up
   ↓
Sign In
```

## 🎨 Design

The UI follows a **basic, clean, and modern design** with a focus on:

- Simple layouts
- Clear typography
- Consistent spacing
- Custom components
- Easy-to-use forms
- Minimal visual clutter

The goal is to keep the design practical and easy to understand while learning Flutter UI development.

- Flutter

## 📁 Project Focus

This is primarily a **UI and Flutter learning project**. The authentication screens and flows are implemented for practice and can later be connected to a real authentication backend such as Firebase, Supabase, or a REST API.

## 🚀 Getting Started

Clone the repository and install the dependencies:

```bash
flutter pub get
```

Run the project:

```bash
flutter run
```

## 📌 Purpose

This project is built for **learning, experimentation, and improving Flutter development skills**, particularly around authentication UI, reusable components, and form validation.
